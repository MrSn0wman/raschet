# Расчёт.рф — онлайн-калькуляторы и инструменты

78 страниц: 60 калькуляторов + 13 новых инструментов + служебные (главная, о проекте, конфиденциальность, реклама, обратная связь, 404). Чистый HTML/CSS/JS, без сборки и зависимостей — GitHub Pages.

**Прод:** https://mrsn0wman.github.io/raschet/

## Что внутри

| Папка/файл | Что это |
|---|---|
| `index.html` | Главная: поиск, «Популярное», каталог 73 инструментов в 13 разделах |
| `<slug>/index.html` | Страницы инструментов (ЧПУ: `ipoteka/`, `kredit/`, `proverka-inn/`…) |
| `calc-*.html` | Редирект-заглушки со старых URL (meta refresh + canonical) — не удалять |
| `assets/` | Шрифты (self-hosted woff2), иконки PWA, `vendor/qrcode.min.js`, `analytics.js` |
| `sw.js` + `manifest.webmanifest` | PWA: полный офлайн (precache всего сайта) |
| `_build/` | Исходники сборки: `parts/` (канонические стиль/шапка/футер/ui.js), `build/` (генераторы), `tools/` (дескрипторы новых инструментов) |
| `backend/` | FastAPI-бэкенд для VPS: курсы ЦБ, обратная связь → email, своя аналитика |

## Дизайн-система

Светлая + тёмная темы (`data-theme` на `<html>`, системная по умолчанию, выбор в localStorage `raschet-theme`). Шрифты: Fraunces (заголовки), Inter (текст), IBM Plex Mono (числа) — локальные, в `assets/fonts/`. Канонические части для правок: `_build/parts/`.

git add -A

GitHub Pages: Settings → Pages → Source: `main`, root. Файл `.nojekyll` уже в корне.

## Обязательные плейсхолдеры (заполнить до/после запуска)

1. **`assets/analytics.js`** — ID Яндекс.Метрики (`YM_ID`) и GA4 (`GA_ID`). Пустые = аналитика выключена.
2. **`feedback/index.html`** — в скрипте массив `MAIL = ['hello', 'raschet', 'rf']` → ваш реальный email (три части: имя, домен, зона). Так адрес не светится целиком в исходнике.
3. **`RASCHET_API_BASE`** — по умолчанию пустой (бэкенд выключен, всё деградирует мягко). После деплоя бэкенда задайте в `_build/parts/ui.js` и пересоберите, или заменой по файлам.

## Бэкенд (опционально, VPS)

`backend/README.md` — полный деплой (systemd, nginx, certbot). Эндпоинты: `/api/rates` (курсы ЦБ), `/api/feedback`, `/api/event`, `/api/popular`. Без бэкенда сайт полностью работает офлайн-first.

## Пересборка (если правите `_build/parts/`)

```bash
python _build/build/build_all.py        # регенерирует весь сайт в ../raschet-site (пути поправить в скрипте)
python _build/build/integrate_pwa.py    # PWA + аналитика + nbsp-фиксы
```
Внимание: скрипты писались под пути `C:\Kimi\...` — при переносе поправьте константы `OLD`, `SITE`, `PARTS` в начале файлов.
